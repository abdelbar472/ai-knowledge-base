# Redis

**What it is:** An in-memory data structure store operating as a cache, message broker, and low-latency database (strings, hashes, lists, sorted sets).

**What it's used for:** Caching hot data, session stores, rate limiting, pub/sub messaging, and real-time leaderboards.
