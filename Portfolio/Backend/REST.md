# REST

**What it is:** An architectural style for web APIs that models resources over HTTP verbs (GET, POST, PUT, DELETE) with stateless request/response semantics.

**What it's used for:** The de-facto standard for public APIs and web backends, offering cacheability, simplicity, and uniform interfaces.
