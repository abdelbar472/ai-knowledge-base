# ScyllaDB

**What it is:** A high-throughput wide-column NoSQL database, API- and protocol-compatible with Cassandra but rewritten in C++ for low, predictable latency.

**What it's used for:** Large-scale, always-on workloads — time-series data, messaging, and caching — where single-digit-millisecond reads at massive write volume are required.
