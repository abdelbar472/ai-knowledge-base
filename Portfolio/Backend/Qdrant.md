# Qdrant

**What it is:** A specialized vector search engine that stores embeddings and performs similarity (nearest-neighbor) retrieval at scale.

**What it's used for:** Semantic search, RAG pipelines, recommendations, and deduplication where data is matched by meaning rather than exact keys.
