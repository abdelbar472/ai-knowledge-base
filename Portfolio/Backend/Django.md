# Django

**What it is:** A "batteries-included" high-level Python web framework shipping ORM, admin panel, auth, templates, and migrations out of the box.

**What it's used for:** Full-stack applications, CMSs, and API backends where structure, security, and rapid development matter. Extends to real-time apps via Django Channels.
