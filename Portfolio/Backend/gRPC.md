# gRPC

**What it is:** A high-performance RPC framework using Protocol Buffers for typed contracts and HTTP/2 for transport, supporting streaming and strongly-typed requests.

**What it's used for:** Efficient service-to-service communication in microservice architectures, inter-service APIs, and polyglot systems.
