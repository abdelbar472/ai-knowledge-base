# WebSockets

**What it is:** A full-duplex communication protocol over a single TCP connection, initiated by an HTTP upgrade handshake.

**What it's used for:** Real-time bi-directional features — live chat, notifications, collaborative editing, and streaming updates — where HTTP request/response latency is unacceptable.
