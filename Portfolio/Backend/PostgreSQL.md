# PostgreSQL

**What it is:** A powerful open-source relational database known for ACID compliance, rich data types (JSON, arrays, spatial), and advanced indexing.

**What it's used for:** Primary structured storage for web apps and services needing reliability, complex queries, and transactional integrity.
