# Express

**What it is:** A minimal and flexible Node.js web application framework that provides a thin layer of routing and middleware on top of Node's HTTP server.

**What it's used for:** Building REST APIs and full web applications in JavaScript/TypeScript. Middleware composes request handling (auth, logging, validation) and routes map HTTP verbs to handlers.
