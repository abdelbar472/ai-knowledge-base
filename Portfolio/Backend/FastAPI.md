# FastAPI

**What it is:** A modern, high-performance Python web framework built on Starlette and Pydantic, with automatic OpenAPI docs and async support.

**What it's used for:** Building fast, typed REST APIs and microservices with automatic request validation, dependency injection, and interactive API documentation.
