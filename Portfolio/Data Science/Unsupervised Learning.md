# Unsupervised Learning

**What it is:** A machine-learning paradigm where models find structure in unlabeled data without target outputs.

**What it's used for:** Clustering (customer/segment grouping, community detection), dimensionality reduction, and anomaly detection; algorithms include k-means, DBSCAN, and PCA.
