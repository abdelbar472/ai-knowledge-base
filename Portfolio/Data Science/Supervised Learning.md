# Supervised Learning

**What it is:** A machine-learning paradigm where models learn from labeled input-output pairs to map features to known targets.

**What it's used for:** Classification (e.g., spam detection), regression (e.g., price prediction), and any task with labeled historical data; algorithms include linear models, trees, and SVMs.
