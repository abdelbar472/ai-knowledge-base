# AI Research Chatbot

A simple AI research assistant built with **FastAPI**, **LangGraph**, **Groq**, and **Tavily**.

Ask any question → the agent searches the web in real-time and returns a clear answer.

---

## Features

- Real-time web search (Tavily)
- ReAct-style agent (LangGraph)
- Fast inference with Groq
- Clean REST API with FastAPI
- Easy to extend into multi-agent systems

---

## Tech Stack

- **Backend:** FastAPI
- **Agent:** LangGraph + LangChain
- **LLM:** Groq (`openai/gpt-oss-120b`)
- **Search:** Tavily Search API
- **Language:** Python 3.10+
