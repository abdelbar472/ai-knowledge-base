# Grafana

**What it is:** An interactive analytics and visualization platform that turns time-series data from sources like Prometheus into dashboards and alerting.

**What it's used for:** Monitoring UIs, SLO/SLA dashboards, anomaly alerting, and unified observability across metrics, logs, and traces.
