# Azure DevOps

**What it is:** Microsoft's suite of development services — Azure Pipelines (CI/CD), Boards, Repos, and Artifacts — tightly integrated with Azure.

**What it's used for:** End-to-end delivery in Microsoft-centric environments, including build/release pipelines, work tracking, and package feeds.
