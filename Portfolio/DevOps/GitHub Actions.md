# GitHub Actions

**What it is:** CI/CD built into GitHub that runs workflows defined as YAML in the repository, triggered by events like pushes, PRs, or schedules.

**What it's used for:** Automating test suites, linting, builds, and deployment — with a large marketplace of community actions.
